Favorite Toggle.pak
===================

Adds the selected game to Favorites, or removes it if it's already there.

Setup: Settings > Assignments > pick a button (L3 or R3 on the Brick) > Favorite Toggle
Then press that button on any game in the main menu, a system folder or a collection.

Favorites are stored in /Collections/1) Favorites.txt and show up under Collections.
The file is compatible with the Favorites pak (ben16w/minui-favorites).
